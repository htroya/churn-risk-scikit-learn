# Selección del umbral

Se eligió el umbral **0.432411** entre los puntos que alcanzan al menos **80% de recall**; dentro de ese conjunto se maximizó precision. La decisión prioriza capturar clientes sintéticos en riesgo y hace visible el costo en falsos positivos. El objetivo debe sustituirse por una función de costos acordada antes de cualquier uso real.
